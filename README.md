# 🛡️ SOC Log Analyzer

A lightweight Python-based security monitoring and log analysis tool designed to simulate a **Security Operations Center (SOC) investigation workflow**.

The tool processes Linux security logs, extracts meaningful security events, identifies suspicious activity, and generates actionable alerts for common attack patterns.

## 🔥 What Makes It Interesting?

Instead of simply searching logs for keywords, the project follows a basic SOC-style workflow:

**Raw Logs → Event Parsing → Detection Rules → Alert Generation → Investigation Summary**

It transforms large amounts of raw log data into security-relevant findings that an analyst can investigate.

## 🚨 Current Detection Capabilities

The analyzer currently detects:

* 🔐 **SSH Brute-Force Attacks**

  * Identifies repeated failed SSH authentication attempts.
  * Groups attempts by source IP.
  * Generates an alert when the configured threshold is reached.

* 🗄️ **Database Brute-Force Activity**

  * Detects repeated PostgreSQL authentication failures.
  * Identifies the attacking source IP, username, database, and affected host.

* 🌐 **HTTP Anomalies**

  * Tracks HTTP `401` and `403` responses.
  * Identifies sources generating repeated authorization/authentication errors.

* ⚠️ **Suspicious IP Activity**

  * Tracks activity associated with source IP addresses.
  * Highlights IPs generating unusually high numbers of events.

* 🔑 **Sensitive Sudo Commands**

  * Detects potentially sensitive administrative commands executed through `sudo`.
  * Currently monitors commands such as `systemctl`, `journalctl`, and `ss`.

* 📊 **SOC Investigation Summary**

  * Provides a final overview of detected security alerts.
  * Shows the number of alert instances generated by each detection category.

## 🧠 Project Speciality

The project uses a **normalized event structure** so that different Linux log formats can be converted into a consistent representation.

Each parsed event can contain information such as:

* Timestamp
* Hostname
* Service
* Process ID
* Username
* Source IP
* Source port
* Event type
* Command
* Database
* HTTP method
* HTTP status code
* Platform

This separation between **log parsing** and **security detection** makes the project easier to extend with additional detection rules.

## ⚙️ Usage

Run the analyzer against a Linux log file:

```bash
python3 log-analyzer.py log.log
```

You can also provide another compatible log file:

```bash
python3 log-analyzer.py /path/to/your/logfile.log
```

The analyzer processes the file and prints security alerts when configured detection thresholds are reached.

## 📋 Example Alert

```text
[ALERT] Possible brute-force activity
Timestamp: 2026-08-29T09:10:39+05:30
Host: srv-auth-01
Service: sshd
User: admin
Source IP: 198.51.100.77
Failed attempts: 18
```

At the end of the investigation, the analyzer produces a SOC-style summary:

```text
========== SOC INVESTIGATION SUMMARY ==========

SSH brute-force alerts:       5
Database brute-force alerts:  1
HTTP anomaly alerts:          1
Sensitive sudo alerts:        4
Suspicious IP alerts:         7

===============================================
```
